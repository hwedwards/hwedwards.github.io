What the pipeline changes

Three separate requests can occupy different stages at once. A single answer still crosses every stage for each generated token, so more stages do not necessarily make it faster. The 4.5 GB example will not fit on one 2 GB node.

What stays local

Flight and collision avoidance never depend on model output or the inference link. The pipeline returns an advisory recommendation to the operator, not a flight command. A stale or incomplete result is withheld.

Scripted CONOPS simulation. No models, photos, aircraft or radio links were used in this walkthrough. Memory and scheduling are illustrative, not hardware measurements. Before deployment, verify per-stage peak memory, link latency and interference with local workloads.
